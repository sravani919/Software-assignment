Repo for escape room mini game for CPSC 8710 

# Prerequisites: 
Node.js version 18.18.0+

# To run: 
1. clone and extract echoroom directory.
2. cd to echoroom/
3. send 'npm run dev' in powershell, or equivalent command in your terminal of choice
4. Open http://localhost:3000 in a browser and enjoy

# AI Usage
Prompt was engineered using an OpenAI ChatGpt based model, and all development work was implemented using IBM Bob.
